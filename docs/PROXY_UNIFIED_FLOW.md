# Единое оформление прокси

Экран «Инструменты → Прокси»: выбрать тип/параметры, рассчитать цену, нажать
«Купить». Единственный обработчик сохраняет заказ через существующий prepare API
и открывает «Мои прокси». На этом шаге ни один режим не списывает деньги.
Изменившаяся цена требует повторного расчёта; повтор запроса использует тот же UUID.

В «Мои прокси» тот же заказ продолжает процесс:

- Ожидает оплаты: подготовлен; для IPv4/ISP/Mobile без permit списание недоступно.
- Обрабатывается: отправляется подтверждение либо сервер обрабатывает оплату.
- Ожидает выдачи: оплата подтверждена, полный товар ещё не установлен.
- Выдан: сервер подтвердил полный набор. Карточки открываются автоматически при
  переходе от ожидания к полной выдаче. После повторного открытия приложения они
  доступны кнопкой «Посмотреть мои прокси».
- Требуется проверка: неопределённая оплата или неоднозначная выдача/таймаут.
- Отменён: заказ закрыт; финансовый результат показан отдельно.

Разрешение и выдача обновляются автоматически, максимум 30 циклов; после паузы
есть «Обновить». История читается из PostgreSQL при каждом открытии страницы.
Контрольный permit остаётся отдельным одноразовым серверным разрешением с лимитом.
Обычная оплата по-прежнему проверяется серверным allowlist. Только карточка заказа
вызывает purchase после подтверждения суммы; каталог больше не дублирует этот код.

## Воспроизводимый тест без реального списания

GitHub Actions **Proxy controlled verification process** запускает
`tests/proxy-unified-browser.cjs`. Для каждого типа браузер 390×844 проходит
реальные React-экраны от «Купить» до автоматического открытия данных подключения.
HTTP-запросы идут к `scripts/proxy_ui_test_server.py`, который вызывает существующие
backend-обработчики и использует одноразовую localhost PostgreSQL. Подменены только
поставщик и авторизация тестового пользователя. Скрипт отказывается запускаться
с другой БД или реальным ключом поставщика и не включается в production.

Проверяются подготовка без оплаты, получение серверного permit, одна тестовая
оплата, задержка свыше минуты, частичный инвентарь без credentials, автоматическое
сопоставление полного набора, обновление карточек, перезагрузка приложения и
один расход в тестовом журнале. Артефакты: `*-unified.png`, `unified-results.json`
и журнал локального HTTP-сервера. Это не платная операция Proxy-IPv4.

## Реальные операции

Изменение интерфейса не открывает массовые продажи и не создаёт permit.
Для реальной контрольной операции сохраняется процедура
[PROXY_CONTROLLED_CHECKOUT.md](PROXY_CONTROLLED_CHECKOUT.md): отдельное разрешение
владельца на UUID/лимит, подтверждение суммы, сверка orderNumber, инвентаря и финансов.
Реальная выдача и пригодность подключения пока не подтверждены платной операцией.
Неподдерживаемый или неоднозначный ответ остаётся на ручной сверке без повторной покупки.
